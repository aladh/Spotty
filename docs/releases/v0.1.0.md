Spotty 0.1.0 is the first app release: a native macOS client for Spotify Premium, built with SwiftUI and AppKit.

## Highlights

- Local audio playback with seeking, gapless transitions, repeat, and persistent shuffle.
- Spotify Connect device discovery, remote playback controls, transfer, and queue display.
- Home, Search, Liked Songs, playlists, albums, and artists.
- Add tracks to owned playlists and remove selected playlist occurrences.
- Native track tables, keyboard navigation, and a centered Home and Search bar.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

Download **Spotty-0.1.0.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.1.0.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.1.0.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.1.0/README.md#first-launch-on-macos).

Open Spotty, choose **Connect**, and authorize Spotify in your browser.
