Spotty 0.1.1 fixes playback-device guidance and restores native macOS window controls.

## Fixes

- When Spotty has joined Connect but cannot identify an active playback device, controls now ask you to select a device instead of incorrectly saying the computer is still joining. Choose **This computer** in Connect to use local playback.
- The sidebar marks the currently playing playlist with a green title and speaker icon, including playback on another Connect device. The indicator clears when playback pauses or disconnects.
- Home and Search now live in the native macOS toolbar. Window controls, title-bar dragging, and double-click behavior are managed by macOS instead of custom button positioning.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

Download **Spotty-0.1.1.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.1.1.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.1.1.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.1.1/README.md#first-launch-on-macos).
