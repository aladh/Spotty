Spotty 0.1.2 reduces playback CPU usage and adds reliable keyboard playback controls.

## Improvements

- Smooth progress now uses Core Animation instead of repeatedly laying out the SwiftUI interface. A measured connected-device playback run used about 95% fewer active CPU samples; results vary by workload.
- System media keys control play/pause, previous, and next through the current playback device. Spotty publishes current track information to macOS and clears it when the session is unavailable.
- Space plays or pauses while browsing the main window. Typing spaces in text fields and using native controls or dialogs keeps its normal behavior; holding Space does not repeatedly toggle playback.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

Download **Spotty-0.1.2.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.1.2.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.1.2.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.1.2/README.md#first-launch-on-macos).
