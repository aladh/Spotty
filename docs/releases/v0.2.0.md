## What’s new

- Check for updates from the Spotty menu, view release notes, and choose when to install and restart.
- Optionally enable automatic update checks. Checks are off by default, and updates never install automatically.
- Update archives and the update feed are authenticated with Ed25519 signatures.

## Installation

This release adds the updater. Install v0.2.0 manually; older Spotty versions cannot update themselves.

Requires an Apple Silicon Mac running macOS 15 or later.

The app is ad-hoc signed and is not notarized by Apple, so macOS will not automatically trust
the download. Hardened runtime remains enabled, with a library-validation exception required
to load Sparkle without an Apple signing identity.
