Spotty 0.2.0 adds built-in updates.

## What’s new

- Check for updates from the Spotty menu, view release notes, and choose when to install and restart.
- Optionally enable automatic update checks. Checks are off by default, and updates never install automatically.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

Install v0.2.0 manually once; older Spotty versions cannot update themselves. Future updates can be installed from the Spotty menu.

Download **Spotty-0.2.0.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.2.0.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.2.0.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.2.0/README.md#first-launch-on-macos).
