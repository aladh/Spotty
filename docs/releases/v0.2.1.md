Spotty 0.2.1 fixes the playback device selection shown after startup.

## Fixes

- This computer now appears in green as ready to play when nothing is playing and no active or identified remote playback device exists.
- Pressing Play in that idle state uses this Mac without asking you to choose a device. If there is no resumable session, Spotty starts the previously displayed track from the beginning.
- Opening Spotty stays silent, and existing remote playback sessions keep their device routing.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

From Spotty 0.2.0 or newer, choose **Spotty → Check for Updates…** to install this release.

For a manual install, download **Spotty-0.2.1.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.2.1.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.2.1.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. macOS will not automatically trust the download. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.2.1/README.md#first-launch-on-macos).
