Spotty 0.2.2 improves playback reliability and restores native Mac interactions across playlists and the player.

## Fixes

- Connection attempts now time out instead of hanging indefinitely, so a failed connection can be retried.
- Tracks that Spotify temporarily refuses to play stay selected with the upcoming queue intact and show retry-later guidance instead of silently advancing.
- This Mac keeps a stable Spotify Connect identity across launches, including after signing out.
- Existing credentials load without unnecessary Keychain access prompts while preserving permission errors.

## Improvements

- Playlist tables again use native multiple selection and keyboard focus behavior.
- The playback position slider restores native pointer tracking, keyboard control, and accessibility behavior.
- Nested links and controls handle clicks and pointer feedback correctly, and Home receives focus when selected from the navigation bar.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

From Spotty 0.2.0 or newer, choose **Spotty → Check for Updates…** to install this release.

For a manual install, download **Spotty-0.2.2.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.2.2.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.2.2.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. macOS will not automatically trust the download. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.2.2/README.md#first-launch-on-macos).
