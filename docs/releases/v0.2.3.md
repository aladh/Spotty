Spotty 0.2.3 restores a more familiar Spotify appearance while retaining native Mac interactions.

## Fixes

- Restore charcoal library selection and neutral-gray track selection, including keyboard multiple selection.
- Restore larger Home and Search controls in the navigation bar.
- Restore the thin Spotify-style progress bar, with a white handle and green played portion during interaction.
- Restore smooth progress movement between playback updates while preserving reduced-motion behavior.

## Improvements

- Keep keyboard and accessibility adjustment, drag-to-seek, and protection against seeking a different track after playback changes.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

From Spotty 0.2.0 or newer, choose **Spotty → Check for Updates…** to install this release.

For a manual install, download **Spotty-0.2.3.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.2.3.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.2.3.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. macOS will not automatically trust the download. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.2.3/README.md#first-launch-on-macos).
