Spotty 0.2.4 restores saved Spotify sign-in without depending on macOS Keychain access.

## Fixes

- Store the Spotify session in a private, owner-only file so later launches can restore sign-in without signing-related Keychain failures.
- Save token replacements atomically and keep corrupt or inaccessible sessions distinct from a missing sign-in.

## Session storage change

After upgrading, connect Spotify in the browser once. Later launches restore the new session file.
Existing Keychain entries are left untouched and are no longer used by Spotty.

The session file is not encrypted and can be read by other software running as your macOS user.
See the [local storage details](https://github.com/aladh/Spotty/blob/v0.2.4/PRIVACY.md#local-storage).
Sign Out removes the active session file.

This release does not address the separate playback-device selection issue.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

From Spotty 0.2.0 or newer, choose **Spotty → Check for Updates…** to install this release.

For a manual install, download **Spotty-0.2.4.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.2.4.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.2.4.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. macOS will not automatically trust the download. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.2.4/README.md#first-launch-on-macos).
