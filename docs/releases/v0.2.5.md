Spotty 0.2.5 improves playback recovery, command handling, and queue continuity.

## Fixes

- Keep playback controls and device information consistent as Spotify Connect updates arrive.
- Prevent queued playback commands from being sent to an outdated account or device.
- Prevent canceled recovery work from restarting an old session after shutdown or account replacement.
- Preserve queue order and selected track occurrences as metadata loads, including duplicate songs and reopening the queue panel.

## Improvements

- Reduce unnecessary interface updates from playback progress and queue metadata loading.
- Report queue and transfer feedback as sent until Spotify confirms the request, and time out commands that never settle after about eight seconds.

## Known limitations

- Scrolling and queue loading may still stutter under heavy workloads.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

From Spotty 0.2.0 or newer, choose **Spotty → Check for Updates…** to install this release.

For a manual install, download **Spotty-0.2.5.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.2.5.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.2.5.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. macOS will not automatically trust the download. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.2.5/README.md#first-launch-on-macos).
