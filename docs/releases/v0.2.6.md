Spotty 0.2.6 strengthens playback and session reliability during account, device, and connection changes.

## Fixes

- Prevent work from an older account, device, or playback session from changing the current session after an asynchronous operation finishes.
- Make reconnect and shutdown handling reject stale engine activity instead of reviving or disconnecting the replacement session.
- Keep playback history aligned with the accepted playback state when an older update arrives after an optimistic command.
- Make overlapping sign-out, shutdown, and session-replacement requests share one orderly teardown.

## Improvements

- Strengthen playback-state validation and automated coverage across macOS and Linux.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

From Spotty 0.2.0 or newer, choose **Spotty → Check for Updates…** to install this release.

For a manual install, download **Spotty-0.2.6.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.2.6.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.2.6.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. macOS will not automatically trust the download. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.2.6/README.md#first-launch-on-macos).
