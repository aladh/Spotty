Spotty 0.3.0 improves browsing continuity and makes playback sessions more resilient under concurrent updates and shutdown.

## Fixes

- Preserve unchanged catalog metadata while playlists and saved-library content refresh, avoiding unnecessary interface invalidations.
- Prevent delayed playback and retry work from outliving the session that created it.
- Keep playback presentation assertions reliable when state changes overlap.

## Improvements

- Consolidate session ownership in a headless runtime while retaining the native Spotify-familiar browsing experience.
- Update the playback engine and strengthen automated checks for session lifetime and release correctness.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

From Spotty 0.2.0 or newer, choose **Spotty → Check for Updates…** to install this release.

For a manual install, download **Spotty-0.3.0.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.3.0.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.3.0.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. macOS will not automatically trust the download. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.3.0/README.md#first-launch-on-macos).
