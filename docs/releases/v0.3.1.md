Spotty 0.3.1 keeps retained Spotify playback intact when you start listening after opening the app.

## Fixes

- Resume the displayed track at its retained position instead of restarting from a playlist’s first track.
- Keep the active playlist highlighted while playback is paused.
- Show a persistent notice and disable Play when the retained Spotify session no longer matches what Spotty displays.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

From Spotty 0.2.0 or newer, choose **Spotty → Check for Updates…** to install this release.

For a manual install, download **Spotty-0.3.1.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.3.1.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.3.1.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. macOS will not automatically trust the download. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.3.1/README.md#first-launch-on-macos).
