Spotty 0.3.2 makes resuming a retained Spotify session more reliable without changing the track or queue shown prematurely.

## Fixes

- Keep the last confirmed track, position, queue, shuffle, and repeat settings visible until Spotify confirms that playback resumed on this Mac.
- Restore the retained queue before playback starts so a track finishing naturally continues with the next track Spotty already showed.
- Keep playback paused and show the recoverable resume notice when Spotify does not confirm the retained session.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

From Spotty 0.2.0 or newer, choose **Spotty → Check for Updates…** to install this release.

For a manual install, download **Spotty-0.3.2.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.3.2.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.3.2.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. macOS will not automatically trust the download. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.3.2/README.md#first-launch-on-macos).
