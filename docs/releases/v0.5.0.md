Spotty 0.5.0 makes browsing, searching, and signing in feel faster and more dependable.

## What’s new

- Browse an artist’s complete discography with more Spotify-familiar grouping and details.
- See Spotify play counts for tracks on album pages when they are available.

## Improvements

- Start browsing your playlists sooner after launch, without waiting for the full library to load.
- Search input and results stay responsive and no longer show an empty state before a search finishes.
- Album and artist pages load visible content sooner and avoid unnecessary work until you choose **Show all**.
- Track selection follows native Mac table behavior more consistently.
- Spotty checks for updates in the background at launch and periodically while running. The **Automatically Check for Updates** toggle has been removed; **Check for Updates…** remains available.

## Fixes

- Avoid briefly showing the Connect screen while an existing Spotify session starts.
- Stay signed in more reliably when the network is unavailable or interrupted during launch.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

From Spotty 0.2.0 or newer, choose **Spotty → Check for Updates…** to install this release.

For a manual install, download **Spotty-0.5.0.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.5.0.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.5.0.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. macOS will not automatically trust the download. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.5.0/README.md#first-launch-on-macos).
