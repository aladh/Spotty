Spotty 0.5.1 brings more Spotify-familiar artist pages and smoother detail-page browsing.

## Improvements

- Browse the playlists Spotify features for an artist in the new **Featuring** row.
- Open an artist’s page directly from their name beneath an album title, with an underline and pointer on hover.

## Fixes

- Keep the artist’s Discography preview in a single row, with sideways scrolling when space is limited.
- Keep playlist headings at the top while loading and fit them correctly in narrow windows.
- Show a pointer when hovering over available Back and Forward buttons.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

From Spotty 0.2.0 or newer, choose **Spotty → Check for Updates…** to install this release.

For a manual install, download **Spotty-0.5.1.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.5.1.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.5.1.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. macOS will not automatically trust the download. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.5.1/README.md#first-launch-on-macos).
