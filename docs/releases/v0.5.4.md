Spotty 0.5.4 fixes paused-session recovery, preserves playback settings, and protects saved collections when a refresh fails.

## Fixes

- Resume a paused session without the controls falling back to Play while audio is running. If the session cannot be safely resumed, choosing the current track or playlist now starts it afresh.
- Keep shuffle and repeat settings when starting a new selection, without reshuffling the order chosen by fewer repeats shuffle.
- Keep playback controls visually steady while a command is in progress, while still preventing duplicate clicks.
- Keep saved playlists and albums when Spotify returns an incomplete or invalid refresh, and show failed library or artist loads instead of treating them as empty collections.
- Confirm successful seeks while a track is playing without the progress indicator reverting. Unrelated browser callbacks no longer interrupt an ongoing sign-in.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

From Spotty 0.2.0 or newer, choose **Spotty → Check for Updates…** to install this release.

For a manual install, download **Spotty-0.5.4.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.5.4.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.5.4.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. macOS will not automatically trust the download. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.5.4/README.md#first-launch-on-macos).
