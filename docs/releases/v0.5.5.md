Spotty 0.5.5 makes playback controls more reliable when recovering a paused session or switching devices.

## Fixes

- Keep Play disabled when a paused session cannot be safely resumed, even after dismissing the message or a failed recovery attempt. Choose a track or playlist to start playback again.
- Keep playback controls steady when delayed updates arrive after Play or Pause, and confirm recovery only when the selected track or playlist is playing.
- Wait for the selected device to report matching playback before treating a device switch as complete.
- Preserve shuffle, repeat, and the chosen track order when starting a selection or recovering playback.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

From Spotty 0.2.0 or newer, choose **Spotty → Check for Updates…** to install this release.

For a manual install, download **Spotty-0.5.5.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.5.5.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.5.5.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. macOS will not automatically trust the download. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.5.5/README.md#first-launch-on-macos).
