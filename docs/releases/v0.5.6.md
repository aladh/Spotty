Spotty 0.5.6 makes quitting more reliable when playback or local app cleanup is slow.

## Fixes

- Give Spotty time to send its final playback position before quitting, even when saving local app data takes longer than usual.

## Known limitations

- If you reopen Spotify after quitting Spotty, Spotify may restore its own earlier playback position. Open Spotify before quitting Spotty to carry over the current position.

## Install

Requires **macOS 15 or newer**, an **Apple Silicon Mac**, and a **Spotify Premium account**.

From Spotty 0.2.0 or newer, choose **Spotty → Check for Updates…** to install this release.

For a manual install, download **Spotty-0.5.6.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.5.6.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.5.6.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. macOS will not automatically trust the download. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.5.6/README.md#first-launch-on-macos).
