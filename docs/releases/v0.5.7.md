Spotty 0.5.7 fixes a startup artwork crash and makes Home and navigation controls steadier on macOS 27.

## Fixes

- Prevent a crash when macOS requests the current track's artwork while Spotty restores a session.
- Keep Home's scroll position when returning to the page or refreshing recommendations, including with always-visible scrollbars.
- Make the full Home, Search, Back, and Forward controls respond to clicks, including along their bottom edges.
- Keep Search centered when the queue is open, and preserve text composition while entering a search.

## Improvements

- Reuse recently viewed album and artist details when navigating back. Revisiting after five minutes refreshes them while keeping previously loaded content visible.

## Known limitations

- If you reopen Spotify after quitting Spotty, Spotify may restore its own earlier playback position. Open Spotify before quitting Spotty to carry over the current position.

## Install

This release raises the minimum requirement to **macOS 27**. Requires an **Apple Silicon Mac** and a **Spotify Premium account**.

From Spotty 0.2.0 or newer on macOS 27, choose **Spotty → Check for Updates…** to install this release.

For a manual install, download **Spotty-0.5.7.zip**, unzip it, and move **Spotty.app** to **Applications**. To verify download integrity, download **Spotty-0.5.7.zip.sha256** into the same folder and run `shasum -a 256 -c Spotty-0.5.7.zip.sha256` before opening the app.

The macOS build is **not notarized or Developer ID signed**. macOS will not automatically trust the download. If macOS blocks the first launch, dismiss the alert, open **System Settings → Privacy & Security**, and choose **Open Anyway** for Spotty. Authenticate and confirm when prompted. See the [README first-launch instructions](https://github.com/aladh/Spotty/blob/v0.5.7/README.md#first-launch-on-macos).
